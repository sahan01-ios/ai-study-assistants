# ai-study-assistants
This project is an AI-powered study helper made with Python. It uses an intelligent agent to process user input and can use tools like calculation or finding information. The system shows how to use AI in a basic way, how to connect tools, and how to give structured answers to study-related tasks in a way that is useful and efficient.
